## [Открыть резюме →](https://digoerisdar.github.io/Resume/)

### Что помогает разобраться в опыте

- **Фильтрация по навыкам.** Выберите нужные навыки — подходящие места работы и проекты останутся выделенными, остальные приглушатся. Блок «Релевантный опыт» покажет суммарную длительность работы в компаниях, где я применял выбранные навыки.
- **Подсказки по терминологии.** Наведите на термин, чтобы прочитать пояснение, не отвлекаясь на поиск определений.
- **Наглядный состав команды.** Для каждого проекта указаны роли и количество участников. При наведении на роль или сегмент диаграммы можно увидеть её долю в команде.
- **Личный вклад в проекты.** Описание разделяет контекст проекта, мою зону ответственности и ключевой вклад. Навыки отмечают то, что я применял лично, а не весь стек проекта.
- **Ссылка с выбранными фильтрами.** Выбор сохраняется в URL — релевантный опыт можно отправить коллеге или нанимающему руководителю.
